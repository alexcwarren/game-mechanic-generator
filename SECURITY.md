# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in Game Mechanic Generator,
please do not open a public GitHub Issue.

Instead, use GitHub's private vulnerability reporting feature if it is enabled
for this repository.

Please include:

- A description of the vulnerability
- Steps to reproduce it
- The affected version
- Any relevant screenshots, logs, or example files

I will review reports as time permits and will provide updates when possible.

## Supported Versions

This project is currently small and actively evolving.

Security fixes will generally target the latest released version.
